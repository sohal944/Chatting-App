# 📌 Real-Time Chat Application  

A **MERN stack** chat application with **real-time messaging** using **Socket.IO**.  

## 🚀 Features  
- 🔹 **Real-time communication** powered by **#SocketIO**.  
- 🔹 **#MERN Stack:** MongoDB, Express.js, React.js, and Node.js.  
- 🔹 **User authentication** and chat history storage using **#MongoDB**.  
- 🔹 **#ChatboxJS** component for interactive messaging.  
- 🔹 **Navigation fixes** for a seamless user experience.  

## 🏗️ Tech Stack  
- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Real-time Communication:** Socket.IO

## 🛠️ Installation  

```bash
# Clone the repository
git clone https://github.com/sohal944/Chatting-App.git

# Navigate to the project directory
cd Chatting-App

# Install backend dependencies
cd server
npm install

# Start the backend server
npm start

# Open a new terminal, navigate to the client directory
cd ../client

# Install frontend dependencies
npm install

# Start the frontend
npm start
